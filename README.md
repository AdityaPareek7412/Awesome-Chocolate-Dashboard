# 🍫 Awesome Chocolate Dashboard

The **Awesome Chocolate Dashboard** is an interactive data visualization project designed to analyze the sales performance, customer trends, and product insights of a chocolate business.  
It helps stakeholders quickly understand key metrics, identify growth opportunities, and make data-driven decisions.

---

## 🔍 Key Features

- **Overall Sales Overview**  
  - Total revenue, total units sold, average order value  
  - High-level KPIs for quick performance tracking  

- **Product Performance**  
  - Best-selling and low-performing chocolate products  
  - Category-wise sales distribution (e.g., dark, milk, white, premium, etc.)

- **Customer Insights**  
  - Repeat customers vs new customers  
  - Most popular chocolate types among different customer groups  

- **Regional Analysis**  
  - Sales comparison across cities/regions/stores  
  - Identification of strong and weak markets  

- **Time-Based Trends**  
  - Monthly/weekly sales trends  
  - Seasonality and festive peaks (e.g., Valentine’s Day, Diwali, Christmas)  

- **Profitability Metrics**  
  - Revenue vs cost vs profit  
  - Most profitable product lines  

- **Interactive Filters**  
  - Filter by product, region, time period, customer segment, etc.  
  - Dynamic visuals that update based on selected filters
